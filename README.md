# MemeMF

![Unreal Engine 5.7](https://img.shields.io/badge/Unreal%20Engine-5.7-blue?logo=unrealengine)
![Git LFS](https://img.shields.io/badge/Git-LFS-orange?logo=git)

**MemeMF** is a chaotic comedy-parody game inspired by the viral "Fever Meme" phenomenon. Developed in **Unreal Engine 5.7**, it features surreal challenges, meta-commentary, and fourth-wall-breaking humor designed to entertain and "troll" the player in a fever-dream-like experience.

## 🚀 Key Features

- **Inspired by "Fever Meme"**: Captured the unpredictable, chaotic essence of the viral hit.
- **Interactive Environments**: Features a detailed **Hospital** setting with custom interactions.
- **Interaction Toolkit**: Built using a robust interaction system for seamless player engagement.
- **Advanced Systems**: Utilizes **Gameplay State Tree** for complex AI and state-driven logic.
- **Modeling Tools**: Leverages UE5's built-in modeling tools for rapid environment prototyping.

## 🛠 Tech Stack

- **Engine**: Unreal Engine 5.7
- **Version Control**: Git with Git LFS (Large File Storage)
- **Key Modules**:
  - `ModelingToolsEditorMode`
  - `GameplayStateTree`
  - `InteractionToolkit`

## 📦 Getting Started

### Prerequisites

- **Unreal Engine 5.7** or later.
- **Git LFS** (Required to pull large assets like textures and maps).

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/S0HAM03/MemeMF.git
   ```
2. **Initialize LFS**:
   ```bash
   git lfs pull
   ```
3. **Open the project**:
   - Navigate to the project folder and double-click `MemeMF.uproject`.
   - If prompted to rebuild modules, click **Yes**.

## 🎮 Gameplay Notes

MemeMF is designed to be a "fever dream" experience. Expect the unexpected:
